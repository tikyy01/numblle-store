# Numblle Store

Веб-магазин современной одежды с возможностью заказать товар с зарубежного маркетплейса.

## Стек
- Frontend: React + Vite
- Backend: Node.js + Express.js
- Database: PostgreSQL

## Запуск backend
```bash
cd server
cp .env.example .env
npm install
npm run dev
```

## Запуск frontend
```bash
cd client
npm install
npm run dev
```

Перед запуском необходимо установить Node.js и PostgreSQL, а также заполнить параметры подключения в `server/.env`.
